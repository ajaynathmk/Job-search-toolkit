# CV and cover-letter conventions: Germany

Used by the CV/letter stage (rules/applications.md) when the posting is in Germany or written in German.

| Item | Convention |
|---|---|
| Name for the CV | **Lebenslauf**. Tabular, reverse-chronological. Two pages at most for a student or early-career applicant. |
| Cover letter | **Anschreiben**: one page, addressed to a named person when the posting gives one, "Sehr geehrte Frau X / Sehr geehrter Herr X", closing "Mit freundlichen Gruessen". |
| Language | Write in the posting's language. A German posting gets a German letter and CV unless it says English is fine. Language quality rules: rules/language-quality.md. |
| Photo | Optional and no longer expected. The anti-discrimination law means employers cannot require one; leave it out unless the posting asks. |
| Personal data | Name, city, phone, email, links. Date of birth, marital status and nationality are no longer expected; a visa or work-permit line is useful for a non-EU applicant (for example "Work permit: student permit, 140 days a year"). |
| Dates | Month/year, "MM/YYYY - MM/YYYY". |
| Education | Degree, university, city, period; thesis title when relevant. German grade equivalents are welcome for foreign degrees (modified Bavarian formula) but not required. |
| Certificates | Zeugnisse go in the application as attachments, not in the CV text. |
| Salary | Do not state an expectation unless the posting asks; then give a range. |
| Signature | A signature under the letter is traditional; a typed name is accepted online. |
| Portals | Many large employers use Workday / SuccessFactors / Personio portals: answer questions in the posting's language; keep a text-only version of the CV ready. |
